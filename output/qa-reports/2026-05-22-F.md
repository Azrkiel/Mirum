## Path to 4/4 (what it took this session)
The first live run was **0/4**, surfacing three real bugs the unit tests (which
bypass the LLM) could not:

1. **SSL** — the container could not reach Gemini (`CERTIFICATE_VERIFY_FAILED`,
   TLS-intercepting proxy). Resolved by mounting the host Windows trust store
   into the container and pointing gRPC/OpenSSL/requests at it.
2. **Pre-existing harness bug** — `run_critic_loop` returns a 3-tuple but the
   eval runner unpacked 2 → every prompt errored. Fixed in `dfda24b`. (0/4 → 3/4)
3. **Regen (60-channel) memory** — valid geometry but peaked ~1.6 GB > the
   1.5 GB sandbox `RLIMIT_AS`, so the sandbox killed it. Fixed by batching the
   channel cuts (`2a8adfa`): peak 1610 → 618 MB, identical solid. Plus a
   retry-hint fix (`01d414b`) steering helix failures to the cooling-channel
   helper. (3/4 → 4/4)
