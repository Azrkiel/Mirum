## Caveats raised (cross-commit, non-blocking)

1. **`channel_count_detected` / orifice count are echoed from the spec, not measured.**
   `verification/geometry.py:180` reads `spec.cooling_channels.count`; tests assert
   `== 60` / `== 24` against the same input (`test_propulsion_pipeline.py:677,742`).
   No `Solids()`/`Faces()` count of the cut geometry. Honestly documented as a stub
   (`geometry.py:90-91`, "Future work: measure via OCC"). Matches handoff §7.

2. **LATENT BUG — `length_fraction` envelope mismatch.** `make_rao_bell_nozzle`
   accepts `length_fraction` in `[0.5, 1.0]` (`cad_utils.py:225`) but
   `propulsion/rao_table.py` `_bracket` raises `ValueError` below `0.6`. Inputs in
   `[0.5, 0.6)` pass the cad_utils guard then crash inside `lookup`. Not covered by
   tests (smoke uses 0.8). → Probe in Phase 3 QA stress (scale/edge axis).

3. **Classifier short-circuit untested + naive substring match.**
   `mentions_propulsion` matches `token in lo` (`rea_schema.py:152`), so benign
   prompts containing "bell crank", "bellhousing", "bell-mouth duct", "throat", or
   "injector" could over-trigger Domain F with no LLM fallback. `test_classifier.py`
   has no Domain F case (positive or negative). → Probe in Phase 3 (cross-domain blend axis).

4. **`run_rea` validator-fed retry loop never executed by a test.**
   `agents.py:244-322` retry/feedback path is unverified end-to-end; only `validate_all`
   is tested in isolation. → Exercised live in Phase 4.

5. **Expansion-ratio test is near-tautological for the bell path.** `exit_area =
   pi*r_t^2*epsilon` divided by `throat_area = pi*r_t^2` cancels `epsilon`
   (`geometry.py:176,178`), so asserting `geometric_expansion_ratio == 12.0` against
   `expansion_ratio=12.0` would pass even if the exit-area derivation were wrong. Only
   the conical `exit_radius` branch gives an independent value, and it is uncovered.

6. **`physics_invariant` / `propulsion_intent` prompt fields are inert.** Present in
   `prompts.json` but read by no harness code; scorer uses `expected_features`.
