### Contract question for the lead (R3 rows)

Table 35 (Evans 1939) centre moments at a/b = 1.0 (0.0231, both) and a/b = 1.1 ((Mx) 0.0264) are outside the R3
band. The converged FD reference (R2) and the FE agree with each other: 0.02291 (0.9 % below 0.0231) and
0.02669 / 0.02672 (1.1 % above 0.0264). These cells are recorded in the
fixture's `known_discrepancies` and asserted explicitly (FE within 0.5 % of R2 and the printed value outside the
band); no test is skipped. The contract says "CL Table 35 all rows"; the lead decides whether those cells stay as
recorded discrepancies or the next contract version drops them. Also: Imrak 2007's "exact" w column is 0.15-0.2 %
above the converged value (Taylor and Govindjee's column in the same table agrees with R2 to 1e-6).
