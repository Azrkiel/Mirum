## Changes and integration surface

api_v1.py supplies strict request models, typed safe errors, rate limits,
no-store responses, exact revision review and finalized-brief-only jobs. Shared
ReviewAcknowledgement enters its strict JSON boundary without weakening Python
or physical validation. Prepared views expose semantic digests and capabilities
provides the exact review_fields list for B12. Lifespan owns one store, shared
proposal ledger, publisher and controller; shutdown closes workers before storage.
Compose requires an application-owned mounted volume under /tmp/mirum, separate
from scratch, and rejects unsupported deployment. Existing access-token middleware
covers these routes; this is not a new tenant boundary. See [API.md](../API.md).

Streaming downloads validate all publication bytes and retain a lease through
iterator completion, exceptions and response cleanup. Historical acceptance with
missing/tampered delivery is explicitly unavailable. Expired compact records and
known expired downloads are 410; unknown IDs/formats are 404. No polling or
download path executes native work or a provider. Legacy APIs/order remain.
