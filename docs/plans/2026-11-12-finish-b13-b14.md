# Finish B13 and B14

accurately scoped release candidate and integration handoff.

verification and exact-byte publication boundaries. Repair only demonstrated
provider/runtime problems, then qualify one fixed implementation/configuration.

cached verification image or the floating production Conda environment.

Gemini preparation provider, Docker/Linux and Playwright/Chromium.

This is a plan, not authorization for new provider calls, implementation,
deployment or main integration. Do not change completion states while planning.
