## 2. Goal state

There is now one prompt box. `/generate` calls `engineering.router.route()`, which is stdlib only.

- **Match:** a prompt that names a registered capability (beam, CO2 dragster, regen chamber, glider CEM) emits one `route` event with `assurance: checked_design`, then returns before REA, Planner or Machinist run. The event includes a rules draft only when that capability has a rules proposer.
- **No match:** every other prompt goes to the LLM pipeline, and every `complete` event carries `assurance: unverified_geometry`.
- **Execution:** all four capabilities run through `/engineering/v1` with deterministic builders and verifiers. Acceptance requires the closed limit table, measurements bound to the generator's own report, and byte digests.
