### 5.3 Merge protocol

1. `gh pr checks <N>`: all checks pass on the **current head**.
2. **Skip counts.** Sum the shard `passed`/`skipped` and compare with main's last run.
   - Main at `e2370cc` was about 4126 passed / 17 skipped. #78 adds a few skips by design: the Dockerfile checks skip inside the native image via `MIRUM_NATIVE_GATE_IMAGE=1`.
   - If skips rise unexpectedly, find the test before merging. The shard reports carry counts but not IDs (§ 8).
3. **Security review** where required.
   - Send the findings back to the agent.
   - Then run a **verification re-review** of `git diff <old> <new>`, limited to the stream's files when main was merged in.
   - Merge only when no CRITICAL, HIGH or MEDIUM is open.
   - LOW items are either fixed or recorded in the handoff.
4. `gh pr merge <N> --merge`, pull, then remove the worktree and branch and delete the remote branch.

### 5.7 Lessons added 2026-11-20

- **Escapes through the Bash tool.** Heredocs and `python -c` passed through the Bash tool can mangle backslash escapes; `\b` became a backspace byte in a regex once. Write regex or escape-heavy text with the Edit/Write tools, and scan new files for `\x08`.
- **Flaky GitHub API.** It times out from this laptop now and then (`dial tcp ... connectex`). Wrap every `gh` call in a retry loop. A watcher that sees no output can wrongly decide the checks have "settled".
- **Untested freeze paths fail on first use.** The first freeze dispatch failed its own clean-tree check (#97). Rehearse every `workflow_dispatch` input on a branch before relying on it on main; branch runs produce `-nonrelease` artifacts.
- **Agent diagnostics in artifacts.** Agents' diagnostics often land in uploaded JSON artifacts, not in the failed-test log. Read the artifact before re-running.
- **Mutation proofs.** Prove mutants with a temporary `worktree-*` branch, which CI runs on push, and delete it afterwards. Black-box tests can miss narrow races; then cite the unit test that the mutant turns red.
- **Agent stalls.** Agents stall or die around 150-200k tokens. One completed at 183k after resuming. For a long stream, start a fresh agent with a precise brief rather than resuming a large one.
